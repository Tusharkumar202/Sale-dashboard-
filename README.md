# 📊 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

An interactive **E-Commerce Sales Dashboard built using Microsoft Power BI** to analyze sales performance, profitability, customer behavior, product categories, payment methods, and regional performance.

The dashboard transforms raw e-commerce data into meaningful visual insights that can help businesses monitor performance and make **data-driven decisions**.

## 🔍 Key Features

* 📈 Monthly **Profit & Loss Analysis**
* 💳 **Payment Method** distribution
* 📦 Quantity analysis by **Product Category**
* 🏆 **Top Performing States**
* 👥 **Top Customers** analysis
* 💰 Profit analysis by **Sub-Category**
* 🎯 Interactive **State & Quarter Filters**
* 📊 KPI cards for important business metrics
* 🎨 Professional and interactive Power BI dashboard

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**
* **Business Intelligence**

## 💡 Business Insights

The dashboard helps identify profitable and loss-making months, understand customer payment preferences, compare state-wise performance, identify top customers, and determine which product sub-categories contribute most to overall profitability.

## 🎯 Skills Demonstrated

**Power BI | DAX | Data Analysis | Data Visualization | Business Intelligence | Dashboard Design | Data Storytelling**

## 📌 Project Goal

The main goal of this project was to practice real-world **data analytics and business intelligence** by converting raw e-commerce data into an interactive dashboard that presents important business insights in a simple and visually effective way.
